# Operating System and Concurrency COMP (G52OSC) Coursework

## Compilation

To compile and run the program, follow these steps:

1. **Prerequisites**

   **GCC Compiler:** Ensure that GCC is installed on your system.
     - **Check GCC Installation:**
       ```bash
       gcc --version
       ```
     - **Install GCC:**
       - **Ubuntu/Debian:**
         ```bash
         sudo apt update
         sudo apt install build-essential
         ```
       - **macOS (with Homebrew):**
         ```bash
         brew install gcc
         ```
       - **Windows:**
         - Install [MinGW](http://www.mingw.org/) or use [WSL](https://docs.microsoft.com/en-us/windows/wsl/install).


## Running the Program

Follow the instruction displayed on the terminal to enter your desired input. The input you need to enter includes:

1. Number of processes
2. Time Quantum
3. I/O Wait Time

And for each process:

4. Arrival Time
5. CPU Burst Time

And that's it! You will expect to see the simulation output, which includes:

1. Process Table
2. Gantt Chart
3. Metrics Calculation (Round Robin Scheduling Performance)
