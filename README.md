# Operating System and Concurrency COMP (G52OSC) Coursework

## Compilation

To compile the program, run the following command:

```
gcc main.c -o main && ./main
```
This will produce an executable file named main.

## Running the Program

Follow the instruction displayed on the terminal to enter your desired input. The input you need to enter includes:

1. Number of processes
2. Time Quantum
3. I/O Wait Time

And for each process:

4. Arrival Time
5. CPU Burst Time

And that's it! You will expect to see the simulation output, which includes:

1. Process Table
2. Gantt Chart
3. Metrics Calculation
